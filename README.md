# Pelan Kekayaan

Laman web peribadi untuk merancang laluan pendapatan dan kekayaan: gambaran dan kalkulator simpanan, kuiz pencari laluan, pelan 90 hari, pengurusan modal dan log pendapatan, serta senarai risiko.

Satu fail HTML tanpa pembinaan (no build). Kemajuan disimpan dalam `localStorage` pelayar.

## Jalankan

Buka `index.html` dalam pelayar. Font dimuat daripada Google Fonts, jadi perlukan internet untuk paparan penuh.

## Hos di GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch, branch `main`, folder `/ (root)`
3. Simpan, dan pautan akan muncul selepas beberapa minit

## Struktur

```
index.html
images/hero.jpg
icons/            ikon laman (192, 512, 180, 32 px)
favicon.ico
README.md
```

Nota: log pendapatan disimpan dalam pelayar pengguna sahaja dan tidak dihantar ke GitHub.
